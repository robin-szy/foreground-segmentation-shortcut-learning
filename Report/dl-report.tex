Deep learning models can rely on background information as a shortcut instead of learning robust object-specific features. This project investigates whether automatic foreground segmentation can reduce such shortcut learning in  a 10-class iNaturalist-12K image classification task. 
Foreground masks were generated with SAM and CLIP, and CNN classifiers were trained with different probabilities of replacing original images by segmented versions. 
%A segmentation pipeline using SAM and CLIP was used to generate foreground masks without manual annotations, and CNN classifiers were trained with different probabilities of replacing original images by segmented versions. 
Partial segmentation reduced the train-validation gap during model selection, suggesting a regularizing effect, but did not consistently improve final test performance. 
Full segmentation substantially degraded performance, likely due to imperfect masks and loss of useful visual context. A pretrained ResNet18 clearly outperformed the custom CNN, showing the benefit of transfer learning on this relatively small dataset.
\end{abstract}

Deep learning models often perform well on benchmarks but may rely on \textit{shortcuts}, i.e. decision rules that fail under challenging or out-of-distribution conditions \cite{geirhos2020shortcut}. This is problematic in settings such as autonomous driving, where models must generalize to unseen environments \cite{Beery_2018_RecogTerra}.
At the same time, prior work has shown that 
image backgrounds can contain highly predictive information and may substantially contribute to classification accuracy \cite{xiao2021noise}.

This project investigates whether automatic foreground segmentation can improve robustness and reduce shortcut learning in biological image classification using a 10-class subset of iNaturalist-12K \cite{inaturalist12k}.
%his project investigates whether reducing background information through automatic object segmentation can improve robustness and reduce shortcut learning in biological image classification. A 10-class subset of the iNaturalist-12K dataset from Kaggle was used \cite{inaturalist12k}. The dataset is well suited for this task because it contains substantial variability in habitats, lighting conditions, and object appearance. 
A segmentation pipeline based on Segment Anything (SAM) \cite{sam_1,sam_2} and CLIP \cite{CLIP} was developed to automatically extract the foreground object without requiring manual annotations. The resulting segmented masks were used to crop images to the region of interest and to train CNN-based classification models. The performance of models trained with this segmentation-based regularization approach was then compared against equivalent models trained on the original, non-segmented images.

Shortcut learning is a limitation of deep neural networks \cite{geirhos2020shortcut}. In ecological datasets, 
background information can become a strong shortcut because images from the same location often share similar environmental context, particularly in datasets collected from fixed animal camera traps \cite{Beery_2018_RecogTerra}. Geirhos et al.\ argue that shortcut learning should not only be studied through in-distribution accuracy, but rather by manipulating the evidence available to the model, such as background, texture, or color, and observing how predictions change \cite{geirhos2020shortcut}. Several studies demonstrate that image backgrounds alone can contain sufficient information for classification \cite{xiao2021noise, obj_recog_without_background}. Xiao et al.\ showed that models trained on ImageNet often strongly depend on contextual background information, while Rosenfeld et al.\ demonstrated that perturbations can alter predictions \cite{xiao2021noise, rosenfeld2018elephantroom}. Geirhos et al.\ further found that CNNs frequently rely more on texture cues than on object shape, which may contribute to such behavior and provides additional motivation for segmentation-based approaches that emphasize object structure over contextual texture information \cite{geirhos2018TextureFeats}.

These findings motivate approaches that explicitly separate foreground objects from their surrounding context. However, many supervised segmentation methods, including segmentation-based variants of YOLO, require manually annotated masks and labels for training, which is highly labor-intensive and not given for the iNaturalist dataset \cite{YOLO}. %Such annotations are not available for the iNaturalist-12K dataset used in this project. 
Segment Anything (SAM) \cite{sam_1, sam_2} provides automatic segmentation proposals  without requiring manual annotation, while CLIP can score image regions semantically using text-image similarity \cite{CLIP}. 
%Segment Anything (SAM) \cite{sam_1, sam_2} provides a way to automatically generate segmentation proposals without requiring manual annotation. To semantically identify relevant masks, this project additionally uses CLIP \cite{CLIP}, which uses text-image similarity to semantically score and label images. 
Such a pipeline is used in this project and is conceptually related to copy-paste augmentation methods \cite{copy_paste_augmentation}, where segmented foreground objects are inserted into alternative backgrounds to improve robustness and reduce contextual bias.


\section{Experiments}

\parhead{Dataset}
The dataset used for this project is a 10-class subset of the iNaturalist-12k dataset available on Kaggle (link in appendix), provided by Aryan Pandey. It contains 12.000 images across biological categories such as Amphibia, Mammalia, and Plantae. The
classes are balanced with 1,200 available images for each of the classes. The dataset was split into 8,000 training images, 2,000 validation images, and 2000 test images, stratified by class.

\parhead{Model architecture}
Figure \ref{arch_custom_model} shows the custom CNN used in this work. It consists of four convolutional blocks, each applying two 3×3 convolutions with batch normalization and ReLU, followed by 2×2 max pooling. Global average pooling and a small fully connected classifier produce the final 10-class logits. As a transfer-learning baseline, a pretrained ResNet18 with ImageNet weights was used by replacing its final layer with a new 10-class classifier.

\begin{figure}
	\includegraphics[width=\columnwidth]{Images/custom_cnn_architecture.pdf}
	\caption{Architecture of custom model}
	\label{arch_custom_model}
\end{figure}

\parhead{Training Details}
Models were trained with cross-entropy loss, AdamW, batch size 32, image size 224×224, random resized crops, horizontal flips, dropout 0.3, weight decay, and gradient clipping at 1.0. Early stopping was used during model selection. Final training used the selected epoch counts without early stopping: 122 epochs for the custom CNN and 30 for ResNet18. For the custom CNN, the final setting used learning rate 0.001 and weight decay 3e-4. ResNet18 used learning rate 0.001 and weight decay 1e-4. Each architecture was finally trained with segmentation probabilities $p \in \{0.0, 0.25, 1.0\}$, where $p$ denotes the probability of replacing an original training image by its segmented version.

\parhead{Results}
The segmentation masks were manually evaluated on 200 images, with 20 samples per class. A mask was counted as good if it captured the main foreground object without large missing regions or excessive background. Mask quality varied strongly between classes: masks were weak for \textit{Animalia}, but reliable for \textit{Aves} (see results in table \ref{tab:mask-quality} of appendix).

During model selection, partial segmentation behaved like a regularizer. For the custom CNN, the non-segmented baseline reached train accuracy 0.700 and validation accuracy 0.551 at its best epoch, while training with partial segmentation reduced the training accuracy to about 0.607 for $p=0.2$ and 0.606 for $p=0.5$, with similar but slightly lower validation accuracy around 0.546 and 0.541. The final test results in Table \ref{tab:final_test_results} show the same overall pattern. Partial segmentation ($p=0.25$) produced almost identical performance to training on original images. For ResNet18, the differences between $p=0.0$ and $p=0.25$ are very small and should not be interpreted as a clear improvement. Even \textit{Aves}, which had the best mask quality, did not clearly benefit from segmentation. Some classes improved in one metric but worsened in another, such as \textit{Plantae} and \textit{Arachnida}. This suggests that partial segmentation acted mainly as a weak regularizer rather than as a systematic performance improvement.

\section{Discussion}
This project investigated whether automatic foreground segmentation can reduce background shortcuts in biological image classification. The results suggest that partial segmentation can act as a mild regularizer, since it reduced overfitting during training, but it did not consistently improve final test performance. Full segmentation performed poorly, probably because the automatically generated masks were imperfect and removed useful visual context in addition to background information.

A key limitation is the quality of the segmentation pipeline. Since masks were generated automatically with SAM and selected using CLIP, errors in mask selection directly affected the training data. Even classes with visually good masks, such as \textit{Aves}, did not clearly benefit, suggesting that background removal alone is not sufficient in this setup. The study was also limited by computational and temporal resources, a small number of final runs, and a relatively small dataset for training CNNs from scratch. This is also reflected by the strong performance gap between the custom CNN and pretrained ResNet18. Future work should repeat the experiment with cleaner segmentation labels, stronger validation across seeds, and controlled background replacement, for example by inserting segmented objects into unusual contexts to directly test shortcut reliance.
